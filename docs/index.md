# HRCE Documentation

Welcome to the **Hybrid Razor Component Engine (HRCE)** documentation.

HRCE is a hybrid rendering engine that works on top of ASP.NET MVC, allowing seamless integration of traditional Razor views with modern Svelte SSR components within the same `.cshtml` file, with complete component isolation (CSS/JS/Runtime) and without changing any part of MVC.

## About HRCE

HRCE provides:
- ✅ Unified pattern for building components
- ✅ Complete CSS/JS/Runtime isolation
- ✅ Razor + Svelte integration without breaking MVC
- ✅ Component-level authorization policies
- ✅ Modern development experience without changing system architecture
